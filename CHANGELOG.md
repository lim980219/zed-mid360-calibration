# Changelog

## 0.1.0 — Initial implementation

- ROS1 bag to BMP/PCD preparation for ZED2 left and MID-360.
- Configurable mounting position and orientation; distances required.
- PointCloud2 and Livox CustomMsg support.
- CameraInfo, timestamps and image motion checks.
- HKU multi-scene calibration orchestration with an isolated ROS master.
- Bidirectional matrices, quaternion, TF launch and projection images.
- Synthetic tests and GitHub Actions workflow.

Validation status: real ROS/C++ integration and sensor accuracy remain unverified.
