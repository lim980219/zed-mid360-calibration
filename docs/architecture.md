# 구조와 실행 흐름

이 패키지는 Python 데이터 준비·실행 관리 계층입니다.
에지 추출 및 Ceres 최적화는 외부 HKU 실행 파일이 담당합니다.

| 파일 | 역할 |
|---|---|
| `cli.py` | CLI, 설정 읽기, 입력 목록, 출력 폴더 및 실패 처리 |
| `config.py` | 기본 설정과 필수값 검사 |
| `bag_io.py` | ROS1 bag 판독, 이미지/포인트 디코딩, PCD 저장 |
| `prepare.py` | 중앙 시간 구간, 영상 움직임 검사, 포인트 누적 |
| `geometry.py` | 설치 자세, 역변환, 투영 |
| `backend.py` | HKU 설정 생성, 프로세스 실행·감시·종료 |
| `report.py` | 외부 파라미터, TF, 투영 이미지 및 검사 결과 저장 |

실행 중 원본 bag은 읽기만 하며, 결과는 새 출력 폴더에 저장합니다.
설정 파일과 bag 카메라 정보로 초기 LiDAR→optical 변환을 만들고,
CameraInfo.R을 적용해 최적화에 필요한 rectified 카메라 변환을 구성합니다.
최적화 결과는 optical 좌표로 되돌려 양방향으로 내보냅니다.

HKU 실행은 별도 ROS master에서 이루어집니다. 기존 로봇 master에 설정을 쓰지 않습니다.
완료, 오류, 사용자 중단 또는 timeout 때 시작한 프로세스 그룹을 정리합니다.
이 모듈의 결과 검사는 최적화 성공이나 정확도를 증명하지 않습니다.
